ЛР5. Нагрузочное тестирование (k6)



\## Описание проекта



Проект выполнен в рамках лабораторной работы № 5. Для нагрузочного тестирования использовался инструмент k6.



Скрипт `load-testing/k6-test.js` выполняет GET- и POST-запросы к сервису HTTPBin, проверяет корректность ответов и собирает метрики производительности.



\## Проведённые тесты



\- \*\*Load-тест\*\* — проверка работы при обычной нагрузке, до 20 виртуальных пользователей.

\- \*\*Stress-тест\*\* — проверка работы при повышенной нагрузке, до 50 виртуальных пользователей.

\- \*\*Spike-тест\*\* — проверка реакции на резкое увеличение нагрузки до 50 виртуальных пользователей.



\## Используемые технологии



\- k6

\- JavaScript

\- HTTP

\- PowerShell

\- JSON

\- HTML Dashboard



\## Пороговые условия



\- 95-й процентиль времени ответа: менее 2000 мс.

\- Доля неудачных HTTP-запросов: менее 5%.

\- Доля успешных проверок: более 95%.



\## Результаты



| Показатель | Load | Stress | Spike |

|---|---:|---:|---:|

| Максимум виртуальных пользователей | 20 | 50 | 50 |

| Количество HTTP-запросов | 4368 | 5198 | 2688 |

| Среднее время ответа | 202,94 мс | 201,55 мс | 203,86 мс |

| p95 времени ответа | 233,69 мс | 227,58 мс | 235,47 мс |

| Доля ошибок | 20,58% | 34,64% | 38,05% |

| Пропускная способность | 18,11 запроса/с | 34,51 запроса/с | 33,33 запроса/с |



\## Вывод



Во всех трёх тестах 95-й процентиль времени ответа был ниже установленного порога. Однако доля ошибок превысила допустимые 5%, а доля успешных проверок оказалась ниже 95%.



Тестирование проводилось на публичном сервисе HTTPBin, поэтому результаты не характеризуют производительность самого Spotify.



\## Запуск тестов



Load-тест:



```powershell

Remove-Item Env:PROFILE -ErrorAction SilentlyContinue

$env:K6\_WEB\_DASHBOARD = "true"

$env:K6\_WEB\_DASHBOARD\_EXPORT = "load-report.html"

k6 run --out json=load-results-20vu.json load-testing/k6-test.js

```



Stress-тест:



```powershell

$env:PROFILE = "stress"

$env:K6\_WEB\_DASHBOARD = "true"

$env:K6\_WEB\_DASHBOARD\_EXPORT = "stress-report.html"

k6 run --out json=stress-results-50vu.json load-testing/k6-test.js

```



Spike-тест:



```powershell

$env:PROFILE = "spike"

$env:K6\_WEB\_DASHBOARD = "true"

$env:K6\_WEB\_DASHBOARD\_EXPORT = "spike-report.html"

k6 run --out json=spike-results.json load-testing/k6-test.js

```



Команды повторного запуска создают новые результаты и могут перезаписать существующие файлы.
